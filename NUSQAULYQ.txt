ҚҰПИЯ ЕСІК · 3D КВЕСТ — ҚЫСҚА НҰСҚАУЛЫҚ
==========================================

ОЙЫН НЕ ТУРАЛЫ
  Екі қабатты үйде өтетін 3D ойын. Ойын үлкен экранда ашылады,
  оқушылар телефонмен QR-кодты сканерлеп қосылады — телефон джойстик болады.
  Бір мезгілде 1–2 ойыншы.

  КВЕСТ       — үйден жасырылған 4 затты тауып, үстелге жинау керек.
                Әр заттың астынан бір сан шығады. 4 сан — есіктің коды.
  ЖАСЫРЫНБАҚ  — біреуі тығылады, екіншісі 2 минутта іздейді.
                Жалғыз ойнаса — компьютер тығылады.


А) GITHUB PAGES АРҚЫЛЫ ЖАРИЯЛАУ (интернет бар болса)
  1. github.com сайтында жаңа репозиторий ашыңыз (Public).
  2. «Add file → Upload files» — осы папкадағы БАРЛЫҚ файлды сүйреп
     апарыңыз (.nojekyll файлы да). «Commit changes» басыңыз.
     Ескерту: .nojekyll көрінбей қалса, «Add file → Create new file»
     арқылы осы атпен бос файл жасаңыз.
  3. Settings → Pages → Branch: main, папка: / (root) → Save.
  4. 1–2 минут күтіңіз. Сілтеме сол бетте шығады:
       https://АТЫҢЫЗ.github.io/РЕПОЗИТОРИЙ/
  5. Сілтемені тақтада ашыңыз → ойын түрін таңдаңыз → «Бастау».
     Оқушылар экрандағы QR-кодты телефон камерасымен сканерлейді.


Ә) ИНТЕРНЕТСІЗ, СЫНЫП WI-FI-І АРҚЫЛЫ
  1. Компьютерде Python болуы керек (python.org, орнатқанда
     «Add python.exe to PATH» белгісін қойыңыз).
  2. start.bat файлын екі рет басыңыз. Ойын браузерде өзі ашылады.
     Қара терезені ойын біткенше жаппаңыз.
  3. Телефондар компьютермен БІР Wi-Fi желісінде болуы керек.
     QR-кодты сканерлеп кіреді.


ПЕРНЕТАҚТАМЕН ОЙНАУ (телефон жоқ болса)
  Мәзірде «+ пернетақта ойыншысы» батырмасын басыңыз.
                    1-ойыншы       2-ойыншы
  Жүру              W A S D        ↑ ↓
  Бұрылу            Q E            ← →
  Жоғары/төмен      R F            PageUp / PageDown
  Әрекет            Space          Enter
  Отыру             C              Shift


ЖИІ КЕЗДЕСЕТІН ҚИЫНДЫҚТАР
  • Телефон қосылмайды:
      - index.html файлын тікелей ашпаңыз — start.bat немесе GitHub
        Pages сілтемесін қолданыңыз;
      - start.bat режимінде телефон мен компьютер бір Wi-Fi-да ма,
        тексеріңіз; Windows брандмауэрі сұраса, «Рұқсат ету» басыңыз.
  • GitHub Pages ашылмайды (404): Settings → Pages баптауын тексеріп,
    2–3 минут күтіңіз; index.html файлы репозиторийдің түбірінде
    (ешбір папканың ішінде емес) жатуы керек.
  • Экран қатып қалды: бетті жаңартыңыз (F5), телефондар өздері
    қайта қосылады.
