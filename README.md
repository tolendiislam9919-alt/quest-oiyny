# Құпия есік · 3D квест

Екі қабатты үйде өтетін браузерлік 3D ойын. Ойын үлкен экранда (компьютер, проектор, интерактивті тақта) ашылады, ал оқушылар **телефонмен QR-кодты сканерлеп** қосылады — телефон джойстикке айналады. Ешқандай қосымша орнату керек емес.

## Ойын түрлері

| Түрі | Ойыншы | Мақсаты |
|---|---|---|
| **Квест** | 1–2 | Үйдің бөлмелерін аралап, жасырылған төрт затты тауып, үстелге жинау. Әр заттың астынан бір сан шығады — төрт сан сыртқы есіктің коды. |
| **Жасырынбақ** | 1–2 | Біреуі тығылады, екіншісі 2 минутта іздейді. Жалғыз ойнаса — компьютер тығылады. |

Экран екі ойыншы болғанда екіге бөлінеді (split-screen).

## Қалай іске қосады

### 1-тәсіл. GitHub Pages (интернет арқылы)

1. GitHub-та жаңа репозиторий ашыңыз (мысалы `kupia-esik`).
2. Осы папкадағы **барлық файлды** репозиторийдің түбіріне жүктеңіз (`.nojekyll` файлы да болсын).
3. **Settings → Pages** → *Source*: `Deploy from a branch`, *Branch*: `main` / `(root)` → **Save**.
4. 1–2 минуттан кейін сайт ашылады:
   `https://<сіздің-атыңыз>.github.io/kupia-esik/`

Телефондар мобильді интернет немесе кез келген Wi-Fi арқылы қосыла береді. Панель мен телефон арасындағы байланыс тегін ашық MQTT-серверлер (shiftr.io, emqx.io, mosquitto, hivemq) арқылы жүреді — біреуі жұмыс істемесе, келесісіне өзі ауысады.

### 2-тәсіл. Интернетсіз, сыныптағы Wi-Fi арқылы

1. Компьютерде [Python](https://www.python.org/downloads/) орнатулы болсын (орнатқанда *Add python.exe to PATH* белгісін қойыңыз).
2. **`start.bat`** файлын екі рет басыңыз — ойын браузерде өзі ашылады.
3. Телефондар компьютермен **бір Wi-Fi желісінде** болса, QR-кодты сканерлеп кіреді.

> `index.html` файлын тікелей екі рет басып ашсаңыз, ойын көрінеді, бірақ телефон оған қосыла алмайды. Сондықтан не `start.bat`, не GitHub Pages сілтемесін қолданыңыз.

## Басқару

**Телефонда:** сол жақтағы сақина — жүру, экранды саусақпен сүйреу — жан-жаққа қарау, «Жүру / Отыру» батырмалары, есік кодын тергіш.

**Пернетақтада** (мәзірдегі «+ пернетақта ойыншысы»):

| | 1-ойыншы | 2-ойыншы |
|---|---|---|
| Жүру | W A S D | ↑ ↓ |
| Бұрылу | Q E | ← → |
| Жоғары/төмен қарау | R F | PageUp / PageDown |
| Әрекет (алу, ашу) | Space | Enter |
| Отыру (жасырынбақ) | C | Shift |

Есік кодын пернетақтадан да теруге болады: сандар, Backspace, Enter, Esc.
